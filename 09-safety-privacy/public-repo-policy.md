# Public Repository Policy

Never commit:
- Real employee names
- Real customer/user data
- Real phone numbers
- Production IP addresses
- Internal network diagrams
- Real hostnames
- Credentials
- Passwords
- API keys
- VPN configuration
- Private URLs
- Production logs
- Confidential incidents
- Real company/project names

Allowed:
- Fictional users
- Reserved/private example IP ranges
- Generic architecture
- Synthetic tickets
- Generic troubleshooting methods
