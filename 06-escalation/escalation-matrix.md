# Escalation Matrix

| Condition | Escalation |
|---|---|
| P1 incident | Immediate senior IT / incident owner |
| Security incident | Security/IT management |
| SLA at risk | Team lead / service owner |
| Vendor-dependent issue | Vendor support |
| Repeated incident | Problem management |
| High-risk change required | Change approval |
| Unknown root cause after standard checks | Senior engineer |
| Data-loss risk | Stop and escalate |

## Escalation Note

Include:
- ticket ID
- business impact
- troubleshooting completed
- current status
- evidence
- requested action
