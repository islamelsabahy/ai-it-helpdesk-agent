# Ticket Intake Checklist

Capture where relevant:

- [ ] Requester
- [ ] Department / business unit
- [ ] Device / service
- [ ] Problem description
- [ ] When it started
- [ ] Number of users affected
- [ ] Business impact
- [ ] Error message
- [ ] Recent change
- [ ] Workaround available
- [ ] Location
- [ ] Contact method
- [ ] Attachment / screenshot reference

Avoid collecting unnecessary sensitive information.
