# Troubleshooting Framework

Use a structured sequence:

1. Confirm symptoms.
2. Confirm scope.
3. Check recent changes.
4. Verify basic dependencies.
5. Use known-safe diagnostic steps.
6. Compare against known issues.
7. Apply low-risk remediation.
8. Validate outcome.
9. Escalate when required.
10. Document resolution.

## Rules

- Do not recommend destructive actions without warning.
- Back up data where appropriate before high-impact changes.
- Avoid registry/firmware/production changes unless approved.
- Never claim success without validation.
